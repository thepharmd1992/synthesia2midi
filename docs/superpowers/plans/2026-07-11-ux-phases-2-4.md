# UX Phases 2-4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the guided calibration, advanced-settings reorganization, and accessibility/localization hardening defined in the approved Phase 2-4 UX design.

**Architecture:** Add focused Qt presentation modules for the Guide, assisted-calibration review, empty state, glossary, and visual verification. Keep workflow behavior in the existing controllers and workflows, preserve every persisted field and public widget attribute, and derive all new progress state from existing `AppState` data.

**Tech Stack:** Python 3, PySide6/Qt, pytest, Qt Linguist (`pyside6-lupdate`/`pyside6-lrelease`).

## Global Constraints

- Work only on `codex/ux-phases-2-4`; do not create a linked worktree and do not push.
- Keep `Left` and `Right` in user-facing calibration language, clarified as Synthesia color families rather than physical keyboard position.
- Preserve all existing config keys, detector parameters, overlay sidecars, signals, and conversion behavior.
- English remains the source/default language; language changes still require restart.
- Write and run a failing test before each production behavior change.
- Keep `uv.lock` untouched.
